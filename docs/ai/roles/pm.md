# PM（主控）角色手册

> 本项目档位 **L2 轻量**：薄手册；方法论权威见 ai-work `规范/10`。  
> 履职前读本册；无完整 L3 任务文体系时，任务依据以派单 / issue / PR 为准。

## 职责

- 拆任务、选路径（直达 / 派工实现 / 独立评审）、写派工阅读清单、收口验收。
- 跨边界沟通收敛到主控出口；方案级裁定留可追溯记录（理由 + 放弃方案 + 影响面）。
- 派出遵守全局 `dispatch.sh` / 协同红线；工人不派出。

## 边界

- 常规分角色任务中不自己写实现、不自己做独立评审；发现问题走裁定与重新派工。
- 低风险「直达」可不激活独立 PM 流程，由当前主控会话按 executor 纪律完成并自检。
- 不修改 `ai-work-spec` 共享件；规范问题登记到规范中心。

## 本项目补充

- **触发**：用户交实质任务或恢复会话时，按全局主控路由 skill 判断路径。
- **派工清单**：见 [`../README.md`](../README.md) §8；路径基准为工作区根或 `src/` Git 根（见指南 §2）。
- **CAO**：多终端编排走 `cao-team`；改档案/端点见 [`../rules/cao-sync.md`](../rules/cao-sync.md)。
- **轮次上限**：同一问题反复修复超过派单约定轮次仍未闭环 → 停手升级，不机械再派一轮。
